# Открытые корпуса разговорной речи для дообучения предсказателя следующего слова

Контекст: цель — коммерческий продукт (предсказание следующего слова в телефонном разговоре). Поэтому вердикт даётся жёстко: «можно в коммерческую модель» ставится только там, где лицензия по первоисточнику явно разрешает коммерческое использование. Пометка на Hugging Face — НЕ первоисточник: загрузивший датасет пользователь мог поставить «MIT» на чужие данные, юридической силы это не имеет.

**Честный итог по русскому:** юридически чистого крупного корпуса именно спонтанных устных диалогов НЕТ. Академические (ОРД, НКРЯ, СпокКорп) закрыты, краудсорсные (Persona Chat) — NC, крупные веб-сборки (Taiga, OpenSubtitles, russian_dialogues) — research/серые. Рабочая стратегия для продукта: чистое ядро (oasst2-ru, Tatoeba, CC0/CC BY источники) + синтетические телефонные диалоги, сгенерированные LLM с разрешающими условиями, + собственные данные звонков с явного согласия пользователей (что в SameVoice и так отдельный трек согласий).

| **ivrit.ai** | [ivrit.ai](https://www.ivrit.ai/en/the-license/), [HF ivrit-ai](https://huggingface.co/ivrit-ai) | >10 000 ч речи (подкасты и др.); crowd-transcribe-v5 — сотни часов человеческих транскриптов | HF audio + json | Собственная **ivrit.ai license** (модифицированная CC BY 4.0): прямо разрешает обучение AI-моделей, **включая коммерческие**; ограничения — только для обучения моделей, запрет дип-фейков голоса, экспортный контроль | **Можно в коммерческую модель** (лучший источник спонтанного иврита) |

**Итог по ивриту:** ситуация лучше русской — ivrit.ai + HebDB дают тысячи часов спонтанной речи с транскриптами под лицензиями, явно допускающими коммерческое обучение моделей; их и брать как основу, CoSIH/MaTaCOp — только для внутренних evaluation.
