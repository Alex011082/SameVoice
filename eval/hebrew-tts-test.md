# Тестовый набор для ивритского TTS

Назначение: сравнивать вендоров синтеза на иврите (ElevenLabs, Cartesia, Google Chirp 3 HD, Azure) по тем местам, где ивритский TTS реально ломается. Судит носитель/владеющий языком — на слух, без чтения текста.

**Предупреждение по ElevenLabs:** по нашим данным на 23.08.2026 иврита нет ни в Multilingual v2, ни в Flash v2.5. Первое, что надо сделать — открыть список языков модели и убедиться. Если иврит там появился — это отличная новость, надо сразу сказать. Если нет, движок «съест» текст и произнесёт его как набор латинских или искажённых звуков; это не баг настроек, а отсутствие языка.

## Как слушать

Каждый пункт проверяет одну вещь. Слушающий не должен видеть текст — только слышать и говорить, что услышал. Оценка по трёхбалльной: **ок** / **понятно, но неестественно** / **неверно**.

---

## 1. Базовая разговорная фраза, мужской род говорящего

```
היי, מה קורה? אני מגיע מחר בערב לתל אביב, נדבר אז.
```

«Привет, как дела? Я завтра вечером прилетаю в Тель-Авив, тогда и поговорим.»

Проверяем: общая естественность, интонация вопроса, ударения.

## 2. То же, женский род говорящего

```
היי, מה קורה? אני מגיעה מחר בערב לתל אביב, נדבר אז.
```

Отличие одно — מגיע → מגיעה. Проверяем, что движок вообще произносит эту форму, а не проглатывает окончание. Для нас критично: род говорящего у нас передаётся в перевод.

## 3. Обращение к женщине и к мужчине

```
את שומעת אותי טוב? אם לא, תגידי לי.
```

```
אתה שומע אותי טוב? אם לא, תגיד לי.
```

«Ты меня хорошо слышишь? Если нет, скажи.» — женский и мужской вариант.

Проверяем различимость форм на слух. Это ровно та пара, которую твоя тестировщица услышит в первую же минуту реального звонка.

## 4. Омографы без огласовок — главный тест

Иврит пишется без огласовок, поэтому одно написание = несколько прочтений. Это основная причина, по которой ивритский синтез бывает неразборчивым.

```
קניתי ספר חדש אתמול בערב.
```
«Вчера вечером купил новую книгу.» — ספר здесь **сефер** (книга).

```
אני אוהב לשתות חלב עם קפה.
```
«Люблю пить молоко с кофе.» — חלב здесь **халав** (молоко), а не **хелев** (жир).

```
הוא דיבר על זה הרבה זמן.
```
«Он долго об этом говорил.» — דיבר как **дибер**.

Проверяем: выбрал ли движок правильное прочтение по контексту. Если читает наугад — это приговор для разговорного продукта.

## 5. Числа, даты, время, деньги

```
הפגישה נקבעה ל-15 באוקטובר בשעה 8:30 בבוקר, וזה עלה 250 שקלים.
```

«Встреча назначена на 15 октября в 8:30 утра, и это стоило 250 шекелей.»

Проверяем: развернул ли цифры в слова, правильный ли род числительных (в иврите числительные согласуются по роду), не прочитал ли время как «восемь тридцать» вместо нормальной формы.

## 6. Смешение иврита с английским (code-switching)

```
שלחתי לך את הלינק במייל, תבדוק את האינבוקס שלך.
```

```
שלחתי לך את ה-link ב-email, תבדוק את ה-inbox שלך.
```

«Отправил тебе ссылку на почту, проверь входящие.»

Два варианта: английские слова записаны ивритом и латиницей. Израильская речь мешает языки постоянно, так что это не экзотика, а норма. Проверяем: не переключился ли движок на английское произношение всей фразы, не прочитал ли латиницу по буквам.

## 7. Аббревиатуры

```
הוא שירת בצה"ל ואחר כך עבר לארה"ב.
```

«Он служил в ЦАХАЛе, а потом переехал в США.»

Проверяем: צה"ל читается как слово «цахаль», ארה"ב — как «арцот ха-брит». Плохой движок произнесёт по буквам.

## 8. Длинная естественная фраза с придаточными

```
תשמע, חשבתי על מה שאמרת אתמול, ואני חושב שאתה צודק, אבל בוא נדבר על זה מחר כשנהיה יותר רגועים.
```

«Слушай, я подумал о том, что ты вчера сказал, и думаю, ты прав, но давай поговорим об этом завтра, когда будем спокойнее.»

Проверяем: дыхание и паузы на запятых, не разваливается ли интонация к концу, не ускоряется ли.

## 9. Эмоция

```
וואו, זה באמת מדהים! לא ציפיתי לזה בכלל.
```

«Вау, это правда потрясающе! Совсем этого не ожидал.»

Проверяем: восклицание звучит как восклицание или как ровный текст.

## 10. Короткие реплики — то, из чего состоит реальный разговор

```
רגע.
```
```
לא, לא זה.
```
```
בסדר, אין בעיה.
```
```
מה? לא הבנתי.
```

«Секунду.» / «Нет, не это.» / «Ладно, без проблем.» / «Что? Не понял.»

Проверяем главное для нас: очень короткие фразы. Многие движки на них дают неестественную интонацию или обрубают начало. А в живом звонке таких реплик больше половины.
