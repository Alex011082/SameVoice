# Замер своего стека на GPU

Проверяем одну вещь: **укладывается ли WhisperLiveKit + VoxCPM2 в две секунды**,
где облачная цепочка даёт четыре. Разбор кандидатов и почему выбраны именно эти
двое — [../self-hosted-stack.md](../self-hosted-stack.md).

## Под

RTX 4090 (24 ГБ), шаблон PyTorch, диск 60 ГБ, ~$0.74/час. VoxCPM2 просит ~8 ГБ,
плюс Whisper и NLLB — суммарно около 16.

## Порядок

```bash
# 1. на поде
bash setup_pod.sh                       # ставит всё и прогревает VoxCPM2

# 2. поднять WhisperLiveKit (в отдельном окне)
whisperlivekit-server --model large-v3-turbo --language ru --target-language he

# 3. замер (залить туда alex_ref.wav из eval/voice-refs/)
python3 bench.py --audio alex_ref.wav
```

## Что означают числа

`распознавание+перевод: до первого коммита` — сколько прошло от начала речи до
первого куска перевода, который **уже безопасно произносить**. Это то место, где
WhisperLiveKit должен обыграть нашу связку: он коммитит, не дожидаясь конца
фразы, а Deepgram+Gemini ждут.

`синтез: до первого звука` меряется **дважды**, и разница между прогонами —
самое интересное в этом тесте. Потоковый API VoxCPM2 принимает текст **целиком**,
поэтому каждый кусок платит за свой prefill. Второй прогон запускает prefill
следующего куска, пока звучит текущий: если выигрыш заметный, заноза лечится
инженерией; если нет — VoxCPM2 не годится как потоковый синтез и нужен другой.

Ориентир для сравнения — медиана **4045 мс** из первого удачного звонка
(§10 [../../docs/07-product-spec.md](../../docs/07-product-spec.md)), где
распознавание дало 766 мс, наш чанкер 1318, перевод 1450, синтез 260.

## Чего этот замер НЕ покажет

Качество. Цифры скажут только про скорость; иврит и похожесть клона судит
основатель на слух, как и всё остальное в этом проекте. Поэтому bench сохраняет
переводы текстом — их надо прочитать, а не только посмотреть на миллисекунды.

Ещё он не проверяет **кросс-языковое клонирование**: референс у нас русский, а
синтез ивритский, и этого не бенчмаркил никто. VoxCPM2 мы слушали на ивритском
референсе — это другой случай.
